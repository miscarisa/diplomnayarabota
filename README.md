# diplomnayarabota

Учебный статический макет страницы просмотра протокола лабораторных исследований, выполненный по мотивам публичного интерфейса ECert.Питомцы для дипломной работы.

## Демо-маршруты

- `/pets/protocol/67c87a58-1c7c-47fc-aa88-5a27c69e4dba` — данные Radja из предоставленного PDF.
- `/pets/protocol/demo-salem` — данные Salem из предоставленного PDF.

## Важно

Проект намеренно помечен как **учебный макет**, закрыт от индексации и не выполняет реальную проверку подлинности документов в ФГИС «ВетИС» / ECert.

## Локальный запуск

Подойдёт любой статический сервер, например:

```bash
npx serve .
```

Для маршрутов `/pets/protocol/...` при локальном запуске через простой статический сервер используйте корень (`/?pet=radja` и `/?pet=salem`) либо запускайте через Vercel, где настроен rewrite в `vercel.json`.
